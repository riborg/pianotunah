# Den native Mac-appen skrivs i Swift, inte Rust

Mac-versionen av Piano Tunah är en SwiftUI-app i Swift 6 för en macOS-version (26 tills GitHubs runners har Xcode 27, sedan 27), som används på en Mac och installeras från GitHub Releases ([ADR 0004](0004-mac-app-updates-itself-from-github.sv.md)). Rust hade inneburit antingen ett Swift-gränssnitt ovanpå ett Rust-bibliotek via UniFFI, eller ett gränssnitt som inte är native, som egui eller Tauri. Kärnan att dela är bara ungefär 1 200 rader JS, och ljudet måste ändå gå genom AVFoundation och Core Audio, så en andra verktygskedja och en brygga kostar mer än de ger. Rust skulle bara löna sig om en kärna också skulle tjäna webben som WASM; webbversionen förblir JS. [English](0001-native-mac-app-in-swift.md). Se [docs/macos-port.sv.md](../macos-port.sv.md).
