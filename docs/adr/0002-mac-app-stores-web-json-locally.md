# The Mac app keeps each piano as a local file in the web's JSON format, with no sync

The Mac app is used on its own, without a phone next to it. Each piano is one JSON file in the app's Application Support folder, in exactly the format the Go server stores. The app is sandboxed, so that folder lies in its container, and the bundle id must never change or the pianos are left in the old container. The app neither talks to the server nor syncs through iCloud. Pianos move between the web and the Mac by export and import. The app decodes leniently, runs the same migration as `normalize` and `migrateSettings`, and keeps fields it does not know, so a file survives the trip in both directions. Server sync remains possible later without server changes, because the format and the `rev` field are kept as they are. Logging in through the OIDC proxy in front of the server is the part that would still need solving. [Svenska](0002-mac-app-stores-web-json-locally.sv.md).
