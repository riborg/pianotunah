# The Mac app keeps each piano as a local file in the web's JSON format, with no sync

The Mac app is used on its own, without a phone next to it. Each piano is one JSON file in `~/Library/Application Support/Piano Tunah/`, in exactly the format the Go server stores. The app is not sandboxed ([ADR 0004](0004-mac-app-updates-itself-from-github.md)), so the files are at that path and not inside a container. The app neither talks to the server nor syncs through iCloud. Pianos move between the web and the Mac by export and import. The app decodes leniently, runs the same migration as `normalize` and `migrateSettings`, and keeps fields it does not know, so a file survives the trip in both directions. Server sync remains possible later without server changes, because the format and the `rev` field are kept as they are. Logging in through the OIDC proxy in front of the server is the part that would still need solving. [Svenska](0002-mac-app-stores-web-json-locally.sv.md).
