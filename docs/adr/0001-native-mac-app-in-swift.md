# The native Mac app is written in Swift, not Rust

The Mac version of Piano Tunah is a SwiftUI app in Swift 6 for the current macOS (27), used on one Mac and installed from GitHub Releases ([ADR 0004](0004-mac-app-updates-itself-from-github.md)). Rust would have meant either a Swift UI on top of a Rust library through UniFFI, or a non-native UI such as egui or Tauri. The core to share is only about 1,200 lines of JS, and the audio has to go through AVFoundation and Core Audio anyway, so a second toolchain and a bridge cost more than they give. Rust would only pay off if one core also served the web as WASM; the web version stays in JS. [Svenska](0001-native-mac-app-in-swift.sv.md). See [docs/macos-port.md](../macos-port.md).
