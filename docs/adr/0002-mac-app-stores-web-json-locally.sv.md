# Mac-appen sparar varje piano som en lokal fil i webbens JSON-format, utan synk

Mac-appen används för sig, utan en mobil bredvid. Varje piano är en JSON-fil i `~/Library/Application Support/Piano Tunah/`, i exakt det format Go-servern sparar. Appen körs inte i sandlåda ([ADR 0004](0004-mac-app-updates-itself-from-github.sv.md)), så filerna ligger på den sökvägen och inte i en container. Appen varken pratar med servern eller synkar via iCloud. Pianon flyttas mellan webben och Macen med export och import. Appen avkodar tillåtande, kör samma migrering som `normalize` och `migrateSettings` och behåller fält den inte känner till, så att en fil klarar resan åt båda hållen. Synk med servern går att lägga till senare utan ändringar i servern, eftersom formatet och fältet `rev` behålls som de är. Det som i så fall återstår att lösa är inloggningen genom OIDC-proxyn framför servern. [English](0002-mac-app-stores-web-json-locally.md).
