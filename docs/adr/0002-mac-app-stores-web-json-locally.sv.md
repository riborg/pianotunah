# Mac-appen sparar varje piano som en lokal fil i webbens JSON-format, utan synk

Mac-appen används för sig, utan en mobil bredvid. Varje piano är en JSON-fil i appens mapp Application Support, i exakt det format Go-servern sparar. Appen körs i sandlåda, så mappen ligger i dess container, och bundle-id:t får aldrig ändras, annars blir pianona kvar i den gamla containern. Appen varken pratar med servern eller synkar via iCloud. Pianon flyttas mellan webben och Macen med export och import. Appen avkodar tillåtande, kör samma migrering som `normalize` och `migrateSettings` och behåller fält den inte känner till, så att en fil klarar resan åt båda hållen. Synk med servern går att lägga till senare utan ändringar i servern, eftersom formatet och fältet `rev` behålls som de är. Det som i så fall återstår att lösa är inloggningen genom OIDC-proxyn framför servern. [English](0002-mac-app-stores-web-json-locally.md).
